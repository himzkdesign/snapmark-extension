# SnapMark

A Chrome Extension for capturing and annotating screenshots.

## Features

- Visible area and full page screenshot capture
- Figma-style annotation pins with cards
- Mockup frames (Browser, Border) with background and shadow options
- Download annotated screenshots as PNG

## Installation (Developer Mode)

1. Clone this repo or download as ZIP
2. Open Chrome → chrome://extensions
3. Enable Developer Mode
4. Click "Load unpacked" → select the screengrab-extension folder
5. Pin SnapMark from the extensions toolbar

## Usage

1. Click the SnapMark icon → capture visible area or full page
2. Use Annotate tool to add numbered pins with notes
3. Use Mockup tool to add device frames and backgrounds
4. Download PNG to export
